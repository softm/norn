# NORN 0.2 · 실행·운영 확인

## 현재 작업 보존

이전 엔진에서 저장하고 종료한 후 새 폴더 전체로 실행합니다. `norn-project.json` 또는 기존 `edit-project.json`을 별도 백업하세요. 이전 v10을 처음 가져오면 `norn-project.json`을 별도 생성하고 기존 파일은 변경하지 않습니다. 모든 옛 옵션이 완전히 호환되는 것은 아닙니다.

같은 원본 폴더에 엔진은 하나만 실행합니다. 다른 엔진으로 동시에 동일한 결과 폴더에 쓰지 마세요. 원본을 수정했다면 ‘원본 다시 읽기’ 후 사용 구간과 자막을 확인합니다.

## 사용자 작업 순서

1. `bash run-norn.command` 실행 → 원본 폴더 선택 → 새로 열린 인증 주소에서 작업합니다.
2. 콘셉트 제목·대략적인 내용을 입력합니다. 실제 설치된 Ollama 모델이 실행 중일 때 분석 버튼을 누릅니다. 자동 분석은 필수가 아니며 직접 입력해도 됩니다.
3. 장면명·타이틀·문구를 확인합니다. 문구는 사용자 확인 사실과 맞아야 합니다. 구간·순서·글씨·배속·음악을 조절합니다.
4. 이 장면 미리보기 또는 전환 경계 미리보기를 확인하고 최종 영상을 생성합니다. 상단이 완료되어도 ‘미리보기’와 ‘최종 파일’은 구분합니다.
5. 게시 준비에서 공개 소개글·채널별 글을 수정해 저장합니다. TXT/ZIP을 사용하되 실제 영상·이미지는 경로의 파일을 직접 첨부합니다.

## Firebase 최초 연결 — 운영자 작업

`bash scripts/connect-firebase.command` → Google 승인 → 실제 목록의 전용 프로젝트·웹 앱 → Google 로그인 제공자/허용 도메인/Firestore 확인 → 배포 대상과 Rules 교체 승인.

배포 주소의 `/setup.html`에서 설정 검사, Google 로그인, 본인 기본 설정 읽기를 진행합니다. **저장·읽기·삭제 검사**는 별도의 명시적 버튼이며 개인 원본/편집이 아닌 임시 검사 문서만 사용합니다.

프로젝트를 실제 저장하고 새로 열기, 다른 계정으로 이전 계정 문서 접근 거부를 확인하세요. 에뮬레이터 검사는 이 운영 확인을 대신하지 않습니다. 관리자 개인키·Firebase 토큰·OAuth 코드를 채팅이나 Git에 넣지 마세요.

## 공개 웹 → 로컬 엔진

실제 Origin만 `--web-origin`으로 허용합니다. 임의 사이트 전체 허용이나 0.0.0.0 바인딩으로 문제를 우회하지 마세요. 브라우저가 로컬 접근을 요청하면 승인하고 토큰은 터미널의 값을 입력합니다. 토큰을 포함한 주소는 다른 사람에게 보내지 마세요.

첫 연결은 새 탭/새로 연 주소에서 시작하세요. 이미 열려 있는 작업실에서는 상단 ‘연결’ 버튼을 사용하면 됩니다. 다른 기기에서 클라우드 프로젝트를 열었다면 ‘현재 편집 유지하고 원본만 연결’을 선택하고 미연결·중복 후보를 확인하세요.

## 릴리스 전 실제 자료 점검

| 항목 | 완료 조건 |
|---|---|
| 짧은 실제 MP4/MOV·사진 | 썸네일, 구간, 자막, 배속, 최종 파일 재생 확인 |
| 긴 고해상도 영상 | 실제 기기 경과시간·메모리·디스크·취소 동작 기록 |
| 8배속 이상 | 원본 플레이어 배속 대신 생성된 미리보기 MP4 확인 |
| 여러 버전 | 각각의 순서·글씨 독립, 출력 비율·게시문 분리 |
| 원본 보존 | 처리 전후 원본 개수·해시·수정시각 일치 |
| 실패·중단 | 기존 완성 파일 보존, 다음 실행에서 중단 상태를 표시 |
| 계정 변경 | 이전 계정의 정보·엔진 연결 코드 정리 |
| 사이트 운영 | 설정 파일 존재와 실제 로그인·저장·도메인 접속 성공 구분 |

## 범위와 제한

원본 삭제, 자동 SNS 게시, 클라우드 원본 저장, 설치 없는 브라우저 FFmpeg, 음성 인식·전사, 전문 다중 트랙 편집, 유료 결제/구독, 완벽한 사실 검증은 포함하지 않습니다. 내장 음악은 프로그램 합성 루프입니다. 사진 확대는 브라우저에서 볼 수 있는 미리보기이며 원본 파일은 첨부 경로로 접근합니다. 모든 조작 효과의 실시간 최종 품질 재생은 아니고 최종 효과는 네이티브 렌더링으로 확인합니다.
