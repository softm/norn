## 구현과 배포를 구분합니다

- 웹 편집기·로컬 FFmpeg 엔진·원본 보호·여러 출력 버전·콘셉트 표본 분석·SNS 준비 코드는 저장소에 있습니다.
- Google 로그인·개인별 Firestore 저장/불러오기·설정 연동 코드와 보안 규칙을 제공합니다.
- 이번에는 실제 CLI 프로젝트/앱 목록을 이용하는 연결 도우미, 공개 SDK 검증, 계정 연결 진단 화면을 추가했습니다.
- Firebase 플러그인은 마지막 조회에서 미설치입니다. 사용자의 설치/Google 승인을 대신 완료하지 않았습니다.
- 운영 Firebase 연결값은 아직 없으며 `enabled: false`를 유지합니다. 실제 OAuth·운영 Rules 배포 완료가 아닙니다.
- Pages 자동 활성화는 기존 실행에서 권한 부족으로 실패했습니다. 현재 워크플로는 미설정이면 배포를 건너뛰고 설정 안내를 남깁니다. 검사 성공은 사이트 배포 성공이 아닙니다.

## 확인한 범위

이번 실행에서 Node 14개, Python 엔진 10개, 오프라인 UI 11항목을 통과했습니다. 연결 도우미는 모의 CLI와 실제 터미널 입출력으로 설정 저장/배포 취소를 확인했습니다. 기존 GitHub Actions의 Firestore Rules 에뮬레이터 검사가 성공한 것도 조회했습니다.

실제 Google 계정으로 승인·프로젝트 생성·운영 배포·사용자 Mac 실행을 수행한 결과는 아닙니다. 실제 Ollama 품질과 장시간 고해상도 영상 성능도 별도 확인이 필요합니다. 원본과 관리자 키·토큰·폰트 파일은 저장소에 넣지 않습니다.
