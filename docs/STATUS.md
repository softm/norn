# NORN 0.1.0 · 구현·검증 상태

기준: 2026-10-18. 기존 SNS CUT v10의 렌더링 모듈 일부를 재사용한 첫 NORN 웹/로컬 분리 버전입니다.

## 구현

- 브랜드: 노른 · NORN, “노른노른하게, 영상을 굽다.”
- 의존성 설치 없는 정적 웹 UI, 명시적 로컬 샘플 체험, 반응형 3패널 장면 편집.
- Google 로그인/로그아웃, 세션 관찰, 사용자별 Firestore 편집 정보 저장/불러오기, 기본 분석 장수 저장 코드.
- 계정 변경 시 이전 계정 프로젝트/연결 토큰 정리. 체험 편집은 명시적 저장 전 클라우드에 전달하지 않음.
- 장면명/타이틀/본문을 편집 패널 상단에 배치, 진행 표시를 화면 상단에 고정.
- 복제·삭제·이동·분할·구간·배속·자막 크기·스타일·전환·음소거·로컬 음악, 여러 출력 버전.
- 네이티브 FFmpeg 구간/속도/전환/음악/자막 합성. 고배속은 실제 프리뷰 파일로 확인.
- 폴더 콘셉트와 영상당 기본 5장 표본의 Ollama 분석 코드, 수동 수정 필드 보호.
- 원본 무복사·무변경. 축소본과 생성 결과만 옆의 업로드준비 폴더에 작성.
- 입력 기반 SNS 문구·실제 원본 첨부 경로, 간단 로컬 아카이브 HTML 생성.
- 토큰·허용 Origin·루프백 Host·안전 경로 검증, 잘못된 생성 요청의 저장 버전 변경 방지.

## 직접 실행한 검사

| 검사 | 결과 | 범위 |
|---|---|---|
| Node 도메인 테스트 | 7개 통과 | 편집 시간·필드 보호·클라우드 허용 필드·독립 버전 |
| Python 엔진 테스트 | 10개 통과 | 실제 HTTP 인증/CORS/Range, 잘못된 요청, FFmpeg 8배속·전환·한글 자막, 원본 해시 |
| Chromium 화면 검사 | 11항목 통과 | 오프라인 DOM 구성, 조작·390px 모바일·상단 고정 진행바 |
| 정적 사이트 빌드 | 통과 | public을 dist로 복사, JS 문법 검사 |
| Firebase Rules 에뮬레이터 | 로컬 미실행 | 테스트 코드 5개 제공. 실행 환경 외부 패키지 설치 불가 |

엔진 시험은 작은 합성 영상/사진을 사용했습니다. 영상 테스트 결과는 240×320, 20fps, 1.8초, 36프레임이며 전체 디코딩을 확인했습니다. 고해상도 장시간 실제 촬영 자료의 성능을 검증한 것은 아닙니다.

브라우저의 실제 URL 접속은 시험 환경 정책(ERR_BLOCKED_BY_ADMINISTRATOR)으로 차단되었습니다. 화면 검사는 about:blank에 실제 UI 코드를 조합하고 비활성 Firebase 설정 및 메모리 저장소를 주입해 수행했습니다. 실제 브라우저↔로컬 엔진 왕복이나 OAuth를 통과했다고 주장하지 않습니다. 로컬 Python HTTP/FFmpeg는 별도로 실제 실행했습니다.

## 연결·배포 상태

- Firebase 플러그인 설치 카드를 다시 표시했으나, 마지막 도구 확인은 `installed: false`였습니다. 설치/Google 권한 승인은 사용자 작업입니다.
- 실제 Firebase 프로젝트 식별값, OAuth 승인, Firestore 운영 Rules 배포, Google 계정 간 격리를 검증하지 못했습니다.
- 기본 설정은 `enabled: false`. Google 로그인 오류를 자동 체험 로그인으로 바꾸지 않습니다.
- 프로젝트를 사용자의 로컬 Firebase CLI로 명시적으로 선택·검사·배포하는 스크립트를 제공합니다. 자격증명은 포함하지 않습니다.
- GitHub 소스 반영/Actions/Pages 결과는 실행 결과를 별도로 확인해야 합니다. 설정 파일이 있다는 것만으로 배포 성공을 의미하지 않습니다.
- 사용자 Mac, 실제 도메인에서 로컬 네트워크 권한 승인, 브라우저 새로고침·다중 탭·실제 Ollama 모델 품질은 추가 검증 대상입니다.

## 기존 v10과 차이

v10 프로젝트를 처음 가져오면 `norn-project.json`으로 별도 저장하며 기존 `edit-project.json`은 수정하지 않습니다. 기존 내장 음악 파일은 새 원본 폴더에 재연결해야 합니다. 모든 v10 옵션과 1:1 호환되는 완성판이라고 보장하지 않습니다. 현재 아카이브는 간단한 원본 참조 갤러리이며, SNS 문구는 입력 기반 템플릿입니다. 자동 게시·음성 전사·클라우드 원본 업로드·브라우저 전용 FFmpeg 렌더링은 없습니다.

실제 운영 공개 전: Firebase 테스트 완료 → 실제 Mac·실제 원본 영상 생성 → 공개 도메인/로컬 엔진 보안 연결 → 기존 프로젝트 이전 확인 순서로 검증하세요.
