브라우저 검사는 GitHub Actions의 Linux Chromium에서 실제 로컬 Python 서버에 접속했습니다. 이번 15항목은 이전 오프라인 DOM 시험이나 모의 HTTP 브리지와 다릅니다. 테스트 원본은 작은 합성 사진·영상입니다. 실제 사용자 Mac·공개 HTTPS 도메인·긴 고해상도 파일에서의 성능을 보장하지 않습니다.

AI 시험은 실제 프레임을 추출하고 모델 응답만 모의로 제공했습니다. 실제 Ollama 모델의 인식/한국어 글/편집 감각을 검증한 것이 아닙니다. Firestore 에뮬레이터 계정 격리 역시 실제 Google OAuth 승인을 대신하지 않습니다.

## 운영 연결 상태

- Firebase 플러그인 자체는 마지막 조회에서 **설치됨**이었지만, 이 채팅에서 Firebase 관리 액션은 제공되지 않았습니다.
- 실제 운영 Firebase 프로젝트/웹 앱 식별값과 사용자 Google 승인을 확보하지 않았습니다. 기본 `public/firebase-config.json`은 **enabled: false**입니다.
- 운영 프로젝트 생성, 로그인 제공자/승인 도메인, 운영 Firestore Rules, Firebase Hosting 배포, `norn.designboard.net` DNS 연결은 완료했다고 표시하지 않습니다.
- GitHub Actions는 테스트·빌드에 성공했지만 **Pages configure/deploy 단계는 저장소 초기 설정 미완료로 건너뛰었습니다. 공개 사이트 배포 완료가 아닙니다.**
- 사용자는 `scripts/connect-firebase.command`로 자신의 Google 계정과 실제 노른 전용 프로젝트를 선택해 연결·배포할 수 있습니다. 다른 서비스 프로젝트와 보안 규칙을 교체하지 않도록 명시적 확인을 요구합니다.

## 의존성 감사 — 별도 미해결 항목

동일 CI의 `dependency-audit` 아티팩트에서 npm 개발/CLI 의존성 경고가 **12건(높음 8, 보통 4)** 남았습니다. 기능 테스트 통과와 취약점 부재는 다릅니다. 자동 제안된 Firebase/CLI 대규모 다운그레이드를 적용하거나 검사를 숨기지 않았습니다. 공개 운영 전에 패치 버전과 영향 범위를 검토해야 합니다. 이 ZIP은 node_modules·Firebase 토큰·관리자 개인키·폰트를 포함하지 않습니다.

## 제공하지 않는 것

실제 SNS 자동 발행, 원본 클라우드 업로드, 브라우저만으로 모든 FFmpeg 실행, 음성 전사, 전문 다중 트랙·비트 싱크·정교한 키프레임 애니메이션, 결제·구독, 모든 사실 오류 자동 차단, 긴 4K 영상 성능 보장은 포함하지 않습니다.
