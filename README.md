# 노른 · NORN

**노른노른하게, 영상을 굽다.**

내 사진과 영상으로 엮어내는 이야기의 실타래.

## 구조

- `public/`: 설치 없이 열어보는 웹 화면과 로컬 체험, Firebase Google 로그인·편집 정보 저장 클라이언트
- `engine/`: 사용자가 선택한 폴더만 읽는 로컬 Python·FFmpeg·Ollama 엔진
- `firebase/`: 사용자별 접근을 제한하는 Firestore Security Rules 및 설정
- `tests/`: 편집 데이터·원본 보존·렌더링·보안 검증

원본 사진·영상·음원은 업로드하지 않습니다. 계정에 저장하는 것은 제목·문구·편집 설정입니다. 로컬 엔진 연결과 Google 로그인은 별개입니다.

## 운영 연결 상태

현재 Firebase 플러그인의 계정 연결이 확인되지 않았습니다. `public/firebase-config.json`은 기본 비활성 상태이며, Google 로그인 실패를 체험 로그인으로 숨기지 않습니다. 실제 Firebase 프로젝트·Google 제공자·허용 도메인·Rules 배포를 확인한 뒤 활성화해야 합니다.

웹 화면, 엔진, 검사·배포 파일을 이 저장소에 순차 반영하고 있습니다. 완료 범위와 검증 결과는 `docs/STATUS.md`에서 확인하세요.

## 개인정보 및 비밀정보

실제 원본·분석 캡처·출력 영상·개인 프로젝트·연결 토큰·Firebase 관리자 키는 이 공개 저장소에 넣지 않습니다. 폰트 파일도 배포하지 않습니다.
